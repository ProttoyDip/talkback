# X3 integration notes

Create one `ToolBridge` per authenticated session, using a session-owned
`httpx.AsyncClient` and `weather_tool(client)` / `web_search_tool(client,
settings.tavily_api_key)`. Close the HTTP client on disconnect.

- Pass `session.send` as `emit`, and `engine.say_filler` as `say_filler`.
- Supply `model_tools()` to the engine and refresh after `set_enabled(names)`.
- Run `execute(raw, turn_id)` in a session-owned task when the engine emits
  `ToolCallRequested`. It accepts either the complete TOOLCALL envelope or its
  inner JSON array. Forward the returned envelope via `engine.send_tool_response`.
- Route validated browser `ToolConfirm` messages to `confirm(message)` on the
  same bridge. Never turn model or tool-result text into a confirmation.
- On disconnect call `close()`, cancel and await execution tasks, and close the
  HTTP client. Keep execution off the audio receive path.
- Only the engine's dedicated tool channel may invoke `execute`. Results are
  never recursively parsed, dispatched, or sent to a memory writer.

The gateway remains unchanged in this package: X1 supplies the engine and task
lifecycle after Phase 0 merges. Settings REST integration is also pending.

## Policy choices

SECURITY.md T5 includes sending data outside: both built-in tools are sensitive,
because weather sends a location and search sends a query. Each call therefore
requires its own approval. Rejected/expired confirmations consume the rate-limit
slot, preventing repeated confirmation prompts from bypassing the limit.

Results keep at most 2,000 total title/URL/snippet characters per source, up to ten
sources per call. Tags, scripts, inline hidden content, and class-bearing content
are removed conservatively; external CSS is not fetched. This is data reduction,
not a guarantee that prompt injection is solved. Delimiter characters are JSON
escaped. Errors and logs contain only fixed codes, session IDs and turn IDs.

Weather uses the first geocoding match and Celsius daily forecasts for today or
tomorrow. No live provider call was made; tests use httpx.MockTransport.
